# Quicksilver audit — 2026-10-14 (scored, blunt)

Baseline: main `bbfda6d`, open PRs #280–#292. Source: audit v5 (12:00 ET) plus the evening CI check.
Scores are 1–10. **Overall 6.2.** The code is in better shape than the ship path: nothing has been proven on a device.

## Weaknesses (ranked)
1. **No device evidence.** CHR-55, HG1 and HG5 are all open. Nothing here claims otherwise.
2. **13 open PRs and nothing merged.** Review depth is thin because the AI review quota is exhausted.
3. **The "on-device first" promise is inverted by default.** `aiServiceEnabled` is off, so a new install has no working route until the owner decides.
4. **Heuristic privacy.** English only, and it misses paraphrases.
5. **CI throughput.** Slow, with occasional runner crashes.

## Strengths
- Architecture rules are tests, not prose.
- Privacy by construction: the on-device route plus a single cloud checkpoint.
- Zero third-party runtime dependencies; least-privilege, pinned CI.
