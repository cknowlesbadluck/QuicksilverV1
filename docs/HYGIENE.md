# Docs hygiene

Rule: one current audit (`docs/AUDIT-2026-09-25.md` or successor dated file) and one *portfolio* roadmap (`docs/PORTFOLIO-ROADMAP-10-PHASE.md`).

This does **not** replace or authorize removing `docs/ROADMAP.md`, the living Quicksilver production roadmap (README already points to it). Keep `docs/ROADMAP.md` updated with product milestones; collapse only the portfolio audit/roadmap pair.

Do not add `docs/PORTFOLIO-AUDIT-YYYY-MM-DD-HHMM.md` files. Update the current audit in place.
