# Docs hygiene

Rule: one current audit (`docs/AUDIT-2026-09-25.md`) and one portfolio roadmap (`docs/PORTFOLIO-ROADMAP-10-PHASE.md`).
This does **not** replace `docs/ROADMAP.md`.
Do not add `docs/PORTFOLIO-AUDIT-YYYY-MM-DD-HHMM.md` files.
`.github/workflows/docs-hygiene.yml` fails the PR if those files reappear.
