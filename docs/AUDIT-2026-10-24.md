### Phase notes and exit criteria

1. **Device fence (CHR-55).** Exit when an unsigned or SideStore IPA built from a green `main` SHA is installed on an iPhone 16e running iOS 27, and the owner records `deviceAcceptance` with:
   - the build SHA and version;
   - a cold launch;
   - Ask on-device;
   - a locked-before-first-unlock → unlock → routing rebuild;
   - Memory add and delete surviving a relaunch.

   Owner-only. Agents never set it.
2. **Memory budget.** Exit when:
   - retention keeps conversation turns at or below `maxConversationItems` (1,000) and at or below 90 days, keeps the newest turns, never prunes notes, preferences, projects, system items or user-sourced turns, and is idempotent (covered by `MemoryBudgetTests` and `MemoryRetentionPolicyTests`);
   - the Spotlight and entity queries match before applying any cap;
   - a device run (after CHR-55) records store size and load time at the cap.
3. **Privacy floor.** Exit when:
   - logs stay private by default, enforced by a test and lint;
   - cloud fallback never sends personal history unless the gate allows it, and non-English input fails closed (#319 → #340 → #342 merged with held-out classifier metrics);
   - Keychain items stay `ThisDeviceOnly`;
   - diagnostics exports are content-free (#374 rebased and merged);
   - Spotlight is opt-in, and opt-out failures are surfaced to the user.
