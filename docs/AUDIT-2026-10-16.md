## Key Features
- On-device-first answers (Foundation Models), with a bound, privacy-gated gateway fallback that is off by default.
- Privacy floor the remote config can't lower; personal turns stay on-device.
- Memory: bounded, decaying, user notes kept as preferences; recall answered from saved notes without a model call.
- Codex honesty surface: route per turn without content, cloud budget, locked/unbound credential state, on-device availability reason.
- App Intents: aspects, and notes as `MemoryEntity` (#317).
- Spatial Sanctum UI with a frozen-motion test mode and a gated accessibility audit.

## Structural Weaknesses
1. **No device loop.** No fresh IPA, no SideStore install, CHR-55 open. The simulator proof (#326) narrows the gap but doesn't close it.
2. **The privacy gate is a heuristic.** English word lists plus NaturalLanguage lemmas. Paraphrases can slip through; non-English fails closed, which costs usefulness.
3. **Two endpoint validators.** Until #325, `MercuryEndpointPolicy` was unused and `GatewayEndpoint` was weaker.
4. **Unused modules.** `Nexus/Integration` (router, MCP client) compiles but isn't used at runtime. That's attack surface and maintenance load.
5. **Crash reporting is removed and there's no device telemetry by design.** Failures on the phone are invisible unless the owner reports them.
6. **The PR backlog is long** (16 open PRs). Merge order matters (#315/#318 before #324).
7. **The `aiServiceEnabled` flag split** (on-device vs. cloud) is still an owner decision.

## Recommended New Implementations
1. **On-device diagnostic export.** A Codex "Export diagnostics" share sheet: route log, Keychain states, availability, build SHA, no content. This makes device bug reports possible without telemetry.
2. **Spotlight opt-in for notes.** `IndexedEntity` on `MemoryEntity`, default off, de-indexed when turned off, with fake-backed tests. Stacks on #317.
3. **On-device paraphrase check for the privacy gate.** When the word lists miss, ask the on-device model a yes/no "is this personal?" classification. It fails closed if the model is unavailable, and never uses the network.
4. **IPA reproducibility script.** `scripts/build-unsigned-ipa.sh` produces an unsigned IPA for SideStore to re-sign, documented in `Documentation/SIDESTORE.md`. Running it stays the owner's job; no signing in CI.
5. **Snapshot tests** for Sanctum and Codex at the largest Dynamic Type size, with no paid dependency (plain `ImageRenderer` comparisons).
